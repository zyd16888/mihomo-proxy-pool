新增分流分类

保存后命中这些地址的流量走本分类出口。本地补充规则优先于订阅规则，后续可在“匹配规则”中编辑。

自动选择与故障转移每 5 分钟检查一次。没有可用成员时阻止连接；手动组也可选择默认代理、直连或拦截。

订阅分流方案

支持标准 Mihomo YAML 或 clash-converter 生成的订阅地址，直接引用现有节点。

关联节点与 DNS

不勾选来源表示使用全部节点；订阅里的节点配置仅用于匹配，不会导入或覆盖节点。

监听、控制接口、TUN 仍由管理器控制。DNS 使用普通域名解析模式，不导入 DNS 监听端口。

组内规则

本地规则优先于订阅规则。修改来源规则会保存为本地覆盖；停用与删除记录在订阅更新后保留。

新增组内规则

不要填写 http:// 或路径。单个 IP 会自动转换为 /32 或 /128。

本地规则始终先于上游规则；本地规则之间数值越小越优先。

规则来源 · 高级管理

来源由当前订阅定义，内容按订阅设置更新。可到所属分类补充域名/IP，或停用对应的来源规则。
