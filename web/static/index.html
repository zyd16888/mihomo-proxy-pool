分流设置

关闭后规则监听不再开放端口。存在启用中的规则监听时无法关闭。

所有规则都未命中时的出口，对应策略组“漏网之鱼”。

高级设置 · 订阅合并与 DNS

与规则集的排序值比较：数值越小越先匹配。默认 500，即位于广告拦截之后、国内外规则集之前。

允许后内核需要下载 GeoIP 与 GeoSite 数据库，首次应用会明显变慢，离线环境可能失败。

规则集下载本身也走规则引擎。选择代理时，节点不可用会导致规则集始终拉取失败。

国外 DNS 用于出境规则集匹配到的域名，其余查询使用国内 DNS。
